# Python Calculator

A desktop calculator built with Python's Tkinter GUI toolkit.

## Run

```sh
cd /Users/mtwhite/calculator
python3 calculator.py
```

Supports addition, subtraction, multiplication, division, decimals, sign changes,
clear, and backspace. Use the buttons or your keyboard. Enter calculates,
Escape clears, and Backspace removes a digit. Operations are performed in entry
order (for example, `2 + 3 × 4 =` produces `20`). Division by zero displays an
error; entering a number starts a fresh calculation.

Requires Python 3 with Tkinter. No pip packages are needed.
